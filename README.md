# Gudang Kayu

Dashboard stok untuk usaha kayu: barang masuk, barang keluar, stok opname, dan master barang, dengan pengatur periode harian, tanggal, dan bulanan.

## Cara pakai
Buka situsnya di browser. Semua data tersimpan di browser perangkat yang dipakai (tidak dikirim ke server mana pun), jadi:

- Data di HP dan laptop terpisah. Pindahkan dengan **Cadangan semua data (JSON)** lalu **Pulihkan dari cadangan**.
- Buat cadangan secara rutin dan jangan pakai mode penyamaran.

## Menerbitkan dengan GitHub Pages
1. Settings → Pages.
2. Source: **Deploy from a branch**, branch **main**, folder **/ (root)**.
3. Simpan. Situs tampil di `https://<username>.github.io/<nama-repo>/` setelah 1–2 menit.
